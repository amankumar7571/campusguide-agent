**Regime:** Institute-wide — calendar listing for 2026-27.

## What this page lists

The official Academic Calendar hub lists three calendars for 2026-27:

- B.Tech & B.Pharm Academic Calendar 2026-27 (First Year)
- Autonomous Batch Academic Calendar 2026-27 (Second and Third Year)
- B.Tech & B.Pharm Academic Calendar 2026-27 (Final Year)

Each opens as a PDF in an in-page modal viewer; no direct PDF URL is exposed, so the full contents (dates, exam windows, holidays) of the calendars could not be retrieved as text.

## Regime note — read this before using the calendars

The three calendars are split by batch regime: the First Year calendar is for new students, the Autonomous Batch calendar covers only the second and third years, and the Final Year calendar is a separate document for the final-year cohort. The final-year (2023–27) batch is the "Affiliated Batch" governed by AKTU rules — its calendar is not the autonomous-batch calendar. Always check which of the three calendars applies to the student's batch before answering a dates question.

## Where the full text lives

The full calendar contents are only available through the modal viewer on the hub page above. A student or admin with browser access should open the hub page and read the relevant calendar PDF there. This entry records only what the hub page itself lists.
